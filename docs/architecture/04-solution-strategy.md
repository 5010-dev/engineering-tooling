# 4. Solution strategy

State: **As-built**

- Distribute one ESM TypeScript package with one non-conflicting CLI and one progressively disclosed Skill.
- Resolve `.github/main` to an exact commit for every authority session and hash every selected source.
- Use off-the-shelf `git`, `gh`, Just, YAML parsing, Zod validation, ESLint, TypeScript, Vitest, Prettier, publint, and Are the Types Wrong.
- Keep `info`, `doctor`, `check`, and `plan` read-only. Make `apply` the only repository-writing command.
- Bind a plan to exact package version, authority commit, repository branch and HEAD, origin digest, complete tracked and untracked worktree digest, source digests, destination digests, and rendered-content digests. Require the digest of the exact user-reviewed plan bytes at apply.
- Copy only the current documentation-owned named examples; record no managed footprint afterward.
