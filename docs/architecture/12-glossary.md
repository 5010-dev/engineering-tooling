# 12. Glossary

State: **As-built**

- **Authority source**: the exact reviewed `5010-dev/.github/main` commit read during an invocation.
- **Copy-once example**: a governance documentation example copied deliberately and thereafter owned by the receiving repository.
- **Golden Path Agent**: the `@5010-dev/golden-path-agent` package and its non-conflicting executable.
- **Managed Skill**: user-local Skill content installed with a package ownership marker; not repository content.
- **Report-only**: visible local evidence that is neither accepted merge policy nor hosting-platform enforcement.
- **Retired executable line**: the historical public `golden-path` releases through `v1.6.1`.
