# Security policy

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a
public issue or pull request for a suspected vulnerability.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. Do not include credentials, customer data, or other sensitive
material beyond what is strictly necessary to reproduce the issue.

## Supported versions

Until the first stable release, only the latest published `0.x` prerelease is
eligible for security fixes. The project is report-only and is not yet a
required organization control.
